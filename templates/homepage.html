Welcome to RASCALL

RASCALL (Rapid Approximate Spectral Calculations for ALL) is a tool for predicting and analyzing molecular spectra. It uses functional group theory to estimate the spectral features of molecules quickly and efficiently.

Use the navigation bar above to access different features of RASCALL:

  • List: Generate lists of molecules based on various criteria.
  • Plot: Create spectral plots for molecules or functional groups.
  • Search: Look up detailed information about specific molecules.
  • Documentation: Learn more about how to use RASCALL and its underlying principles.
